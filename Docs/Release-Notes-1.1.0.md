# Stickyy 1.1

## Floating Notes

- Press your Stickyy shortcut to toggle a clean, movable note above every app.
- Keep working in the active menu-bar note or create a fresh note every time.
- Floating notes work across Spaces and alongside full-screen apps.
- The focused panel keeps the note editor only—no header, sharing button, or
  Clipboard Pills.
- The original material and Liquid Glass appearances both remain available.

## In-app Updates

- Added secure Sparkle updates with signed downloads and automatic checks.
- Added **Check for Updates…** and an automatic-check toggle in Settings.
- Existing v1.0.1 users need to install v1.1 manually once. Later releases can
  be installed from inside Stickyy.
