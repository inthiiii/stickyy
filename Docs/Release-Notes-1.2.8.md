# Stickyy 1.2.8

## Faster structure, more accurate paste

- The floating-note paste action now inserts the most recently copied text,
  even when older Clipboard Pills are pinned above it.
- Type `- ` at the beginning of a line for a solid bullet. Press Return to
  continue the list, or Return on an empty bullet to finish it.
- Type `->` to insert a right arrow.
- Type `---` to create a section divider. A compact dot navigator appears on
  the right edge so you can jump between sections in either note style.
- Liquid Glass keeps its background blur when section navigation appears.
- The dot navigator stays compact and scrollable with long notes, and can be
  turned off under Editor in Settings.
- Right-clicking the menu-bar icon now opens Settings reliably.
- A small, non-intrusive ready card appears for three seconds when Stickyy
  starts or launches at login.
