# Stickyy 1.2.9

## Floating note interaction

- The floating note now receives clicks and scrolling after switching from
  another app.
- Typing and scrolling no longer affect the window behind Stickyy.

## Clean paste

- Text pasted from websites and documents is inserted as plain text and adopts
  the note's current style.
- Paste as Plain Text is available from the editor context menu and with
  Command–Option–Shift–V.
- Image and file attachment pasting continues to work as before.

## Updating

- Existing Stickyy users can install this release from **Check for Updates**.
- The direct-download DMG remains a free Apple Development-signed test build
  and is not Apple-notarized. First-time users may need to approve Stickyy in
  **System Settings → Privacy & Security** after attempting to open it.
