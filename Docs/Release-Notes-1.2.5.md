# Stickyy 1.2.5

## Reliable updates from here forward

- Fixed the sandbox permission Stickyy uses to connect to its update installer.
- Added a release check that prevents an incorrectly configured updater from
  being published again.
- Future signed updates can be installed directly from Stickyy after 1.2.5 is
  installed.

## One-time repair for older installations

Stickyy 1.2.1 and earlier contain the broken installer permission, so those
versions cannot replace themselves. Their update window now directs you to the
Stickyy website instead of attempting an installation that will fail.

Download 1.2.5, quit Stickyy, and drag the new copy into Applications to replace
the old copy. Your existing notes and settings remain on the Mac.

All features introduced in 1.2.1 are included in this release.
