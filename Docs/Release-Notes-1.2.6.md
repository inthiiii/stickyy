# Stickyy 1.2.6

## A new scratchpad in one keystroke

- Press **Command-N** while the menu-bar scratchpad is open.
- Stickyy creates a new blank scratchpad and switches to it immediately.
- Your previous note stays safely stored in the scratchpad library.

This small release is also the first end-to-end test of the repaired in-app
updater introduced in Stickyy 1.2.5.
