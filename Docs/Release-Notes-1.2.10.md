# Stickyy 1.2.10

## Stickyy Timer

- Set a timer for up to 60 minutes from the menu-bar scratchpad or floating
  note.
- The compact timer icon smoothly expands into a live countdown pill.
- A sound and macOS attention request let you know when time is up.
- Stickyy sends a local notification when the timer finishes, including while
  another app is in front.
- When both note windows are closed, the regular menu-bar icon smoothly turns
  into a live Liquid Timer pill. Opening either note restores the regular icon.
- The menu-bar pill now returns to the normal icon before the scratchpad opens,
  keeping its popover arrow perfectly aligned.
- A completed timer turns green in the note header; click it once to reset it
  to the compact timer icon.
- Hide Stickyy Timer completely from Settings whenever you prefer a more
  minimal workspace.

## Smoother Clipboard Pills

- Clipboard Pills now respond freely to horizontal trackpad gestures.
- Vertical mouse-wheel movement over the shelf is translated into horizontal
  scrolling, making every pill easier to reach.

## Numbered lists

- Begin a line with `1. ` and press Return to continue with `2.`, `3.`, and
  onward.
- Press Return on an empty numbered item to finish the list.

## A more complete welcome

- Onboarding now introduces the Liquid Timer.
- A final feature grid highlights Multiple Notes, pinned notes, text formatting,
  and chapter sections.
- The startup card now simply says that Stickyy is back in the menu bar.

Existing Stickyy users can install this release from **Check for Updates**.
The direct-download DMG remains a free Apple Development-signed test build and
is not Apple-notarized. First-time users may need to approve Stickyy in
**System Settings → Privacy & Security** before opening it.
